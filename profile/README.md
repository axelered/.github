### How it works

| Area            | Detail                                                                                         |
| --------------- | ---------------------------------------------------------------------------------------------- |
| **Platform**    | Six modules: capture, understand, decide, review, integrate and govern.                        |
| **Mechanism**   | Rules, extraction models and agents are chosen per step.                                       |
| **Review**      | Cases below a confidence threshold go to a person for review.                                  |
| **Integration** | We integrate with existing systems and build connectors, services and dashboards where needed. |
| **Delivery**    | One process at a time, from assessment through a pilot to production.                          |
| **Go-live**     | The engineers who build a process stay on it and report its results every month.               |
